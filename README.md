# Learning Factorized Motion for Agile Aerial Robots

An interactive workshop presentation by Yinuo Zhang, Computer Science and Software Engineering, University of Canterbury.

[Open the presentation](https://antiparadox.github.io/aerial-motion-workshop/)

Use Space or the right arrow to reveal the next point. Use the left arrow to go back. The frame dots jump to a frame. Press F for full screen.

The website includes the two local simulation clips and the interactive helicopter model. The factorization and generation diagrams illustrate proposed research, rather than validated learned-model results.
